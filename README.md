# Engineering & Design Portfolio — v0.1.0

## Publish
1. Create a public repository named `maldyy.github.io` on GitHub.
2. Extract this ZIP and upload its contents to the repository root (not the enclosing folder). Commit to main.
3. Open Settings > Pages. Under Build and deployment choose Deploy from a branch, main, / (root), Save.
4. Wait for the Pages deployment and open https://maldyy.github.io.

## Add a project
Copy an existing Markdown file in `_projects`, change its filename and front matter (title, category, context, summary, order), and edit the body. The homepage automatically lists the collection. Store approved images under assets/images and reference them using `![Description](/assets/images/filename.jpg)`.

Initial project summaries are drafts; review before public release. Abstract diagrams are decorative, not actual project drawings. Do not upload proprietary employer material or personal contact details without review. Resume and contact pages are intentionally incomplete. English only in this version.
